Y Y – Use the texture’s intensity value to displace in the Y direction. Z Z – Use the texture’s intensity value to displace in the Z direction. NORMAL Normal – Use the texture’s intensity value to displace along the vertex normal. CUSTOM_NORMAL Custom Normal – Use the texture’s intensity value to displace along the (averaged) custom normal (falls back to vertex). RGB_TO_XYZ RGB to XYZ – Use the texture’s RGB values to displace the mesh in the XYZ direction.
